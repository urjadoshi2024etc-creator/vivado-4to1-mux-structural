# 🔀 Structural 4:1 Multiplexer Using 2:1 Multiplexers

A hierarchical **Verilog HDL** implementation of a **4:1 Multiplexer (MUX)** constructed using **three 2:1 Multiplexer submodules**.

The project is designed, elaborated, and verified using **Xilinx Vivado**, with both **RTL schematic analysis** and **behavioral simulation**.

---

## 📌 Project Overview

A **Multiplexer (MUX)** is a combinational digital circuit that selects one input from multiple input signals and routes the selected signal to a single output.

In this project, a **4:1 Multiplexer** is constructed structurally using **three 2:1 Multiplexer modules** arranged in a two-stage hierarchical structure.

The project demonstrates:

- Structural Verilog HDL design
- Hierarchical module instantiation
- Reusable 2:1 MUX submodule
- Structural implementation of a 4:1 MUX
- Behavioral testbench development
- RTL elaboration and schematic analysis
- Behavioral simulation using Xilinx Vivado

---

## 🎯 Objectives

The main objectives of this project are:

1. To understand the operation of a 2:1 Multiplexer.
2. To construct a 4:1 Multiplexer using multiple 2:1 Multiplexers.
3. To implement hierarchical and structural RTL design in Verilog.
4. To understand module instantiation and signal interconnection.
5. To verify the design using a Verilog testbench.
6. To analyze the RTL schematic generated by Xilinx Vivado.

---

## 🏗️ Design Architecture

The 4:1 MUX is implemented using **three 2:1 MUXes** in two stages.

### Stage 1

Two 2:1 MUXes operate in parallel:

- `m0` selects between `in[0]` and `in[1]` using `sel[0]`.
- `m1` selects between `in[2]` and `in[3]` using `sel[0]`.
